# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证。

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`

## 三色分布口径（全局唯一，禁止混用）

选定架构：**打开总览即时重算（`recompute_on_open`），不设持久分布账/世代/快照。**

- 唯一事实源：分区册 `partitions.tier`（温层列）。总览三色分布条每次打开按
  `status='在册'` 分区的温层列分组重算，纯函数 `services/distribution.py::replay_distribution`，
  同输入必同输出，可由选定口径随时重放。
- 三类业务回执（登记 / 迁移完成 / 销毁成功）只改分区册，且各自在单事务内原子提交
  （`BEGIN IMMEDIATE` + WAL + busy_timeout，写事务串行化）；因此分布条与分区册永远同刷，
  不存在“分布已变、分区册未变”的半截回执，并发登记与迁移完成不漂档。
- 诊断页（目录互证）只读、只对账（`/api/分布对账`），不产生业务回执；任何诊断改数请求
  （`/api/分布对账/改数`）整笔 403 拒绝，互证流水/目录清单改数盖不住重算，不会“假绿”。
- 读路径走 `db_ro()` 只读快照，写路径走 `db()` 写锁事务，读写互不阻塞。

另一备选“以分布账世代为准”的方案未采用，全库不得引入世代账或分布快照与其混用。
路径级差与保留争用不在本需求范围内。
